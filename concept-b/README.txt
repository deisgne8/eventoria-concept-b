EVENTORIA — PORTABLE CONCEPT B

This package contains the current Concept B source, images, SVGs, fonts,
audio, 3D model, and local Three.js dependencies. No Codex account keys,
node_modules, or build step are required.

RUN ON ANOTHER COMPUTER
1. Extract this ZIP.
2. Install Python 3 if it is not already available.
3. Open a terminal in the extracted Eventoria-Concept-B folder.
4. Run: python3 -m http.server 4181 --bind 127.0.0.1
   Windows: py -m http.server 4181 --bind 127.0.0.1
5. Open http://localhost:4181/concept-b/ in a modern browser.
6. Leave the terminal running. Ctrl+C stops the server.
Do not open index.html directly: the 3D module and assets need HTTP.

CONTINUE IN ANOTHER CODEX ACCOUNT
Open the extracted folder as a project in Codex. Ask:
“Read HANDOFF.md, run the local preview, and continue editing Concept B.”
The files transfer the website; the original chat history does not transfer.

The contact form is a preview and does not send email.
The localhost link only works on the computer running the server.
